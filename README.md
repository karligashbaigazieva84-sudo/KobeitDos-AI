# KobeitDos AI

Бастауыш сынып оқушыларына көбейту кестесін үйретуге арналған қазақ тіліндегі интеллектуалды веб-платформа.

## Мүмкіндіктер

- 2-ден 9-ға дейінгі көбейту кестесін үйрену;
- 5 сұрақтан тұратын ойын;
- әр кестені қамтитын 16 сұрақтық диагностика;
- әлсіз кестені автоматты анықтау және жеке жаттығу;
- диагностикаға дейінгі және жаттығудан кейінгі нәтижені салыстыру;
- оқушының жеке есебі және браузерде сақталатын сынып нәтижесі;
- телефон мен компьютерге бейімделген интерфейс.

## Іске қосу

Жоба сыртқы серверді қажет етпейді. `index.html` файлын браузерде ашуға немесе жергілікті сервер іске қосуға болады:

```bash
python3 -m http.server 8000
```

Содан кейін `http://localhost:8000` мекенжайына өтіңіз. Нәтижелер осы браузердің `localStorage` жадында сақталады.

> Бастапқы Colab notebook (`кобейту14.ipynb`) зерттеу және салыстыру үшін өзгеріссіз сақталған.
